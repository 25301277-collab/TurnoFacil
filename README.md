# TurnoFácil

Portada oficial preparada para GitHub Pages desde `main`, carpeta raíz `/`.

## Archivos

- `index.html`: versión final de la portada.
- `style.css`: estilos adaptables a computadora y celular.
- `script.js`: menú, búsqueda, filtros, preguntas y galería.
- `assets/`: logotipo, imagen principal, icono y nueve piezas de campaña.
- `.nojekyll`: publicación directa de los recursos.

## Reservas y administración

GitHub Pages sirve archivos estáticos y no ejecuta el servidor Node/SQLite del proyecto. Los botones de reservas, consulta y administración abren el servicio existente de TurnoFácil:

https://turnofacil-web-production.up.railway.app/

No se incluyen bases de datos, credenciales ni enlaces privados de activación. La disponibilidad de la agenda depende de ese servicio. La agenda no tenía negocios registrados durante la revisión.

## Publicar

En Settings → Pages, elegir Deploy from a branch, rama `main` y carpeta `/ (root)`.

Fuente: entrega final local `Entrega_TurnoFacil_Publicada/proyecto_local`, fechada el 19 de octubre de 2026. Se conservan su diseño y contenido; los formularios que necesitan servidor se sustituyen por enlaces a la agenda activa.
